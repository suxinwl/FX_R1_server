斐讯 R1 专用小智 —— 一键安装说明（V2.0.5）

★ 前置：音箱固件必须是 3448
   本程序只支持 3448 固件的斐讯 R1，安装前请先把固件升到 3448 版本。
   固件不对就装上，可能出现唤不醒 / 没声音 / 打不开 web 控制台（8080）。
   脚本会自动校验，不是 3448 就锁住安装菜单，只能先去升固件。

本版（V2.0.5）相对 V2.0.4 的变化，主要是「有声书 / 节目」整条链路：
   · 节目页（新）：搜索只列书名，点书名弹窗选集（首行=最近播放，带集数搜索）；
     一集放完自动续下一批，不用回网页手动点
   · 整本集表缓存 + 点的这集先出声：一本书枚举一次就记住，第二次点开秒出
   · 我的节目（新）：有声书收藏，和音乐收藏分开；在播时点一下 ☆ 就收进来
   · 播到才取链：队列里是惰性地址，真播到那一集才解析；解析不到就原地停，
     绝不把「非音频」丢给播放器（以前会出现「取链成功但没声音」）
   · 按书续播：每本书记住「听到第几集、第几秒」，说「继续听 XX」就接着播；
     交叉听两本书也不会串集
   · 下一集 / 上一集：以正在播的那一集为基准，手动跳集、网页跳集后都不会错位；
     网页上播书时那两个按钮会自动变成「下一集 / 上一集」
   · 防误触：刚播完一集不再被误判成「列表听完」而自作主张跳回别的书
   · 本地有声书库（新）：NAS 的 /audiobook 里有的书，语音点播优先放本地文件，
     不再去在线取链；来源标「📖 本地节目」
   · 录音链路两个老问题：搭车模式下补一条常驻播放流给 AEC 做参考（回声 / 半聋）；
     ALC 开着时固定增益置灰（以前能点但根本不生效）
   · 网页：节目三栏 / 铃声缓存框内滚动不再无限变长；搜索框删空立即回全列表；
     页面不再被浏览器强缓存 10 分钟（「改了不生效」的老毛病从根上去掉，
     顶部「页面已过时」横幅点一下会先注销旧缓存再强刷）
   · NAS 服务端升到 v1.2.3：读有声书目录自带的封面/简介/演播信息，
     并修掉「容器偶发意外停止」（播放器一暂停，转发流 20 秒后被 abort 把进程带走）
   详细清单见同目录 README.md，构建源码在 源码/ 里。

怎么用：
1. 确认音箱已开启 adb 网络调试，且和电脑在同一个网络下
2. 双击 一键安装.bat 运行（也可以在 CMD 里运行；不要用 Git Bash）
   注意：请用 CMD 或 PowerShell，Git Bash 会吞掉命令里的引号
3. 输入音箱 IP，例如 192.168.2.5:5555（直接回车用默认）；用 USB 数据线的请输入 usb
4. 菜单选 [1] 一键安装，等它自动装完即可

装完之后：
5. 浏览器打开 http://<音箱IP>:8080/ → 顶部「激活」卡片取 6 位激活码 → 到小智服务端绑定
6. 用本地自建服务器的，还要再用菜单 [6] 填一次服务器地址（重装会清空 OTA 地址）

菜单：
 [1] 一键安装（so宿主 + 主包 + 控制台包 + 拉起）  推荐
 [2] 只装 / 重装 so 宿主   （XiaoZhi_SoHost_V2.0.1.apk）
 [3] 只装 / 升级 主包     （XiaoZhi_Unisound_V2.0.5.apk）
 [4] 只装 / 升级 控制台包 （XiaoZhi_EchoService_V2.0.5.apk）
 [5] 打开 Web 控制台（:8080）
 [6] 设置服务器地址（官方 / 本地自建）
 [7] 重启小智      [8] 重启音箱
 [9] 查看运行日志  [s] adb shell
 [0] 退出

【注意】
- 三个 apk 都要装，缺一不可：XiaoZhi_Unisound（主包）、XiaoZhi_EchoService（控制台包）、
  XiaoZhi_SoHost（Opus so 宿主）。无 root 上 so 只能由系统安装器从 APK 解出来。
- 控制台在 :8080。装完脚本会自动等它就绪再提示你打开；等不到会直接告诉你怎么查。
- 上传失败脚本会自动重试一次；WiFi adb 偶发静默截断，重跑一次就好。
- 测试音量请控制在 30% 以内（player 档位 0..15 ⇒ 最多设 4），避免炸音伤耳朵。
- 装完任何一个包，播放进程都会重启 ⇒ 播放列表清空，收藏、闹钟、「我的节目」不受影响，
  重新点一次「导入播放列表并播放」即可。
- 从旧版升级后，浏览器里可能还压着 V2.0.4 的旧页面（那一版给了 10 分钟强缓存）：
  等顶部「页面已过时」横幅出来点一下，或手动刷新一次；本版之后不再有这个问题。
- 本地有声书库需要 NAS 端 ≥ v1.2.1：把 R1XiaoZhi_MediaServer_v1.2.3/ 覆盖到 NAS 后
  docker compose up -d --build（见该目录 README.md）。
- 音乐资源因版权原因不随包提供，需要自己准备 + 自己部署 NAS 音乐服务。
- 从旧版升级直接覆盖安装，收藏、闹钟、我的节目与设置都保留。
